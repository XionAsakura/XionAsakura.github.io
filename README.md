# Ruben Rodriguez — CS 499 Computer Science ePortfolio

This repository hosts my CS 499 Computer Science Capstone ePortfolio for Southern New Hampshire University.

## ePortfolio

The GitHub Pages site presents my professional self-assessment, capstone code review, and three required enhancement categories:

- Software Design and Engineering
- Algorithms and Data Structures
- Databases

## Featured Artifacts

### IT 140 Zelda-Inspired Text Adventure

The project is used for the software design and algorithms categories. The enhancements demonstrate object-oriented design, clearer state management, input handling, breadth-first search, graph traversal, data-structure selection, validation, and automated testing.

### CS 465 Travlr Getaways

The full-stack application represents the database category. The enhancement demonstrates MongoDB and Mongoose schema design, validation, indexing, CRUD and REST API improvements, filtering, authentication handling, secure error responses, and testing.
