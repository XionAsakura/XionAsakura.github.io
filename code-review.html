Milestone One

Code Review

The code review established the starting point for the capstone enhancements. I reviewed the original IT 140 text-based game and the CS 465 Travlr Getaways application, explained their existing functionality, identified weaknesses, and planned changes for software design, algorithms and data structures, and databases.

Purpose of the Review

The review focused on structure, documentation, control flow, defensive programming, efficiency, testing, security, and maintainability. The goal was not to criticize older work for being different from my current work. Instead, I used the original projects as a baseline and identified changes that would clearly demonstrate growth during the capstone.

Artifacts Reviewed

IT 140 Text-Based Game

The Zelda-inspired Python game was reviewed twice from different perspectives. For software design, I focused on global state, mixed responsibilities, command handling, replay behavior, and maintainability. For algorithms, I focused on the room dictionary as a graph, inventory storage, graph validation, and the lack of a traversal algorithm.

CS 465 Travlr Getaways

The full-stack application was reviewed around its MongoDB and Mongoose data layer, CRUD controllers, REST API behavior, Angular administration application, authentication, validation, testing, and error handling.

Planned Outcome

The review produced a practical enhancement plan that connected each proposed change to a problem in the original code. The final artifact pages in this portfolio show how those plans were implemented and tested.

From Review to Enhancement

Original Findings

  • Global state and tightly coupled game logic
  • No graph traversal or map validation
  • List-based inventory when uniqueness mattered
  • Inconsistent database validation and data types
  • Raw or inconsistent error behavior
  • Limited filtering and query controls
  • Testing gaps and stale generated tests

Final Enhancements

  • Player and Game classes with clearer responsibilities
  • Breadth-first search hint system and graph validation
  • Set-based inventory with predictable display order
  • Stronger Mongoose schema validation and indexes
  • Controlled API and authentication errors
  • Whitelisted filtering, sorting, and pagination
  • Automated tests plus live application verification
